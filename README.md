# baiyuze.github.io

这个仓库只放跳转页：项目 CopySync 在 2026 年 10 月更名为隔空贴（PasteFerry），
仓库从 baiyuze/copysync 改名为 baiyuze/pasteferry，官网现已迁至 https://pasteferry.cc/。
这里的 copysync/ 目录把旧网址逐页直接跳到新域名，保留查询参数与锚点，
404.html 接住其余的 /copysync/ 和 /pasteferry/ 路径。

This repository redirects the old CopySync website (/copysync/) directly to
https://pasteferry.cc/, preserving page paths, query strings, and fragments.
The project lives at https://github.com/baiyuze/pasteferry.
